# 탱크 대전 게임 (Tank Game)

## 1. 프로젝트 소개

이 프로젝트는 Python과 Pygame으로 만든 탱크 대전 게임입니다. 공개SW실무 수업에서 GitHub의 기존 Pygame 탱크 게임 프로젝트를 가져와 팀원들과 함께 기능을 추가하고 수정했습니다.

플레이어가 탱크를 조작해 맵 안에서 전투를 진행하는 게임이며, 기본 플레이 외에도 여러 게임 모드와 맵을 선택할 수 있도록 구성했습니다.

## 2. 주요 기능

- 메인 메뉴: 게임 시작, 게임 모드 선택, 도움말, 종료 메뉴를 제공합니다.
- 맵 선택: 여러 가지 맵 중에서 플레이할 맵을 선택합니다.
- 탱크 조작 및 전투: 탱크를 움직이고 포탄을 발사해 상대와 대전합니다.
- 게임 모드: 기본 모드 외에 아이템, 스피드, 고스트, 코인 배틀 등의 모드를 제공합니다.
- 맵 데이터 관리: 텍스트 파일을 이용해 맵의 벽, 장애물 등의 배치를 관리합니다.
- 이미지 및 사운드: 게임에 필요한 그래픽 이미지와 효과음을 사용합니다.

## 3. 사용 기술

- Python
- Pygame
- 파일 입출력: 텍스트 파일로 맵과 게임 모드 정보를 관리
- 객체지향 프로그래밍: 탱크, 발사체, 장애물, 화면(Scene) 등을 클래스로 분리

## 4. 폴더 구조

```text
SW-main/
├── main.py              # 게임 실행 파일
├── requirements.txt     # 필요한 Python 라이브러리
├── tanks/
│   ├── scenes/          # 메인 메뉴, 맵 선택, 게임 모드 등 화면
│   ├── sprites/         # 탱크, 포탄, 장애물 등의 게임 객체
│   ├── ui/              # 버튼, 글자, 화면 메시지
│   ├── constants.py     # 화면 크기 등 공통 설정
│   ├── grid.py          # 맵의 격자와 화면 좌표 처리
│   ├── input.py         # 키보드와 마우스 입력 처리
│   ├── images.py        # 이미지 불러오기
│   └── sounds.py        # 사운드 처리
├── levels/              # 기본 게임 맵
├── modemap/             # 게임 모드별 맵
├── data/                # 이미지 및 사운드 리소스
└── fonts/               # 게임 폰트
```

## 5. 설치 및 실행 방법

### 1) Python 설치

Python을 설치합니다. 프로젝트가 오래된 버전의 Pygame을 기준으로 작성되었을 수 있으므로, 실행 오류가 발생하면 Python 및 Pygame 버전을 확인해야 합니다.

### 2) 프로젝트 폴더 열기

압축을 풀고 `SW-main` 폴더를 터미널 또는 명령 프롬프트에서 엽니다.

### 3) 필요한 라이브러리 설치

```bash
python -m pip install -r requirements.txt
```

### 4) 게임 실행

```bash
python main.py
```

## 6. 코드 살펴보기

| 파일/폴더 | 역할 |
|---|---|
| `main.py` | Pygame을 초기화하고 게임 화면을 반복해서 갱신합니다. |
| `tanks/scenes/main_menu.py` | 시작 메뉴를 표시하고 메뉴 버튼을 처리합니다. |
| `tanks/scenes/game_mode.py` | 게임 모드 선택 화면을 관리합니다. |
| `tanks/scenes/level.py` | 기본 맵에서 진행되는 게임 화면을 담당합니다. |
| `tanks/scenes/coinmode.py` | 코인 배틀 모드를 처리합니다. |
| `tanks/scenes/ghostmode.py` | 고스트 모드를 처리합니다. |
| `tanks/sprites/tank.py` | 탱크 객체의 동작을 관리합니다. |
| `tanks/sprites/shell.py` | 발사된 포탄의 동작을 관리합니다. |
| `tanks/grid.py` | 격자 좌표를 실제 화면 좌표로 변환합니다. |
| `levels/` | 기본 게임 맵 데이터가 저장되어 있습니다. |
| `modemap/` | 각 게임 모드에서 사용하는 맵 데이터가 저장되어 있습니다. |

## 7. 조작 방법

정확한 키 설정은 게임 내 도움말 화면과 입력 처리 코드를 기준으로 확인하세요. 실행 후 메인 메뉴의 `Help` 항목을 확인하면 게임에서 안내하는 조작법을 볼 수 있습니다.

## 8. 실행 시 참고사항

- `data`, `levels`, `modemap` 폴더는 게임 실행에 필요한 파일이므로 폴더 구조를 유지해야 합니다.
- `pygame.error`, 이미지 파일을 찾을 수 없다는 오류가 발생하면 프로젝트 루트 폴더에서 `main.py`를 실행하고 Pygame 설치 여부를 확인하세요.
- 저장소에 포함된 `.gdrwuzj` 확장자 리소스 파일은 프로젝트에서 사용하는 이미지 파일입니다. 임의로 이름이나 위치를 변경하지 않는 것이 좋습니다.
- 팀 프로젝트의 수정본이므로 일부 모드나 기능은 추가 확인이 필요할 수 있습니다.

## 9. 프로젝트를 통해 배운 점

기존 오픈소스 프로젝트의 코드를 읽고 구조를 파악한 뒤 팀원들과 기능을 추가하는 경험을 했습니다. 게임 화면을 Scene 단위로 나누는 방식과 탱크·포탄 등의 객체 관리, 맵 파일을 활용한 데이터 관리 등 Python 기반 게임 개발의 기본 흐름을 익힐 수 있었습니다.
